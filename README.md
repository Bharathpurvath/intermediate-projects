# Intermediate Projects — Bharath B

Published gallery: https://bharathpurvath.github.io/intermediate-projects/

This repository contains 16 separate project pages and each project's React frontend, FastAPI backend, setup README, and dependency files.

## Important

GitHub Pages serves the static gallery and source code. It does not run the Python/FastAPI backends, so the full-stack applications need to be started locally by following each project's README. No local databases, logs, dependency folders, or `.env` secrets are included.

The Learning Management System page also links to its browser-only edition, hosted in the Beginner Projects repository.
